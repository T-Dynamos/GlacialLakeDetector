# GlacialLakeDetector Miscellaneous Scripts & Forensic Archive

This directory archives supplementary data generation scripts, pre-processing utilities, and granular forensic validation artifacts developed during the scientific validation gates of Project GlacialLakeDetector.

---

## 1. Directory Contents

### Supplementary Analysis & Processing Scripts
- **`generate_validation_suite.py`**: End-to-end multi-site scientific validation and report compiler.
- **`compile_standardized_features.py`**: Feature synthesis and standardization across all six study sites.
- **`compile_standardized_sar_and_susceptibility.py`**: Comparative radar backscatter and susceptibility matrix compiler.
- **`generate_completeness_audit.py`**: Site-by-site data completeness and uncertainty auditor.
- **`generate_catalogue.py`**: Metadata catalog generator.
- **`generate_inventory.py`**: Trans-Himalayan lake inventory compiler.
- **`generate_preview_atlas.py`**: Geographic footprint and map preview generator.
- **`generate_footprint_map.py`**: Spatial bounding box footprint mapper.
- **`generate_ladakh_candidates.py`**: Regional candidate lake extraction pipeline.
- **`generate_ladakh_map.py`**: Ladakh regional cartographic overview generator.
- **`generate_drang_drung_reports.py`**: Drang-Drung multi-temporal analysis report compiler.
- **`generate_kyagar_reports.py`**: Kyagar ice-dammed lake multi-temporal report compiler.
- **`generate_rumbak_reports.py`**: Rumbak moraine breach forensic report compiler.
- **`generate_rumbak_qc_figures.py`**: Rumbak radar calibration and quality-control figure generator.
- **`preprocess_south_lhonak.py`**: South Lhonak benchmark comparison preprocessor.
- **`process_deepen_three_sites.py`**: Deepened radiometric investigation for Gya, Parkachik, and Phyang.
- **`process_dem_corrections.py`**: Copernicus DEM valid-data boundary masking and gradient correction.
- **`process_drang_drung_pipeline.py`**: Drang-Drung proglacial snout time-series pipeline.
- **`process_kyagar_pipeline.py`**: Kyagar ice dam recurrent flotation pipeline.
- **`process_rumbak_forensics.py`**: Rumbak August 2021 moraine breach forensic reconstruction.
- **`process_segmentation.py`**: Multi-temporal shoreline segmentation comparator.
- **`capture_all_screens.py`**: Automated headless UI screenshot capture utility.

### Forensic Validation Reports & Data Registers
- **`scientific_validation_audit.md`**: Master scientific validation audit across all study sites.
- **`ahp_methodology.md`**: Theoretical framework and pairwise matrix for AHP GLOF susceptibility modeling.
- **`susceptibility_sensitivity_analysis.md`**: One-At-A-Time (OAT) weight perturbation sensitivity report.
- **`dem_and_terrain_validation.md`**: Copernicus GLO-30 DSM terrain, slope, and gradient validation audit.
- **`sar_processing_validation.md`**: Sentinel-1 C-band SAR radiometric calibration and RTC processing audit.
- **`model_readiness_assessment.md`**: Pre-implementation modeling readiness evaluation gate.
- **`all_sites_comparative_features.md` / `.csv`**: Reconciled comparative physical features table across all sites.
- **`claim_evidence_register.csv`**: Granular evidence and source-provenance matrix.
- **`ahp_pairwise_matrix.csv`**: Normalized 8-factor AHP pairwise comparison matrix.
- **`glof_susceptibility_results.csv`**: Final quantitative susceptibility scores and classifications.
- **`historical_event_label_register.csv`**: Verified GLOF event labels and physical mechanism classifications.
- **`site_analysis_completeness.csv` / `.md`**: Multi-temporal data completeness matrix.
- **`validated_six_site_features.csv`**: Fully audited physical measurements dataset.
- **`data_catalogue.csv`**: Comprehensive satellite and terrain data catalogue.
